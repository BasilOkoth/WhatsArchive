# Local APK build

Recommended toolchain:
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Android SDK Platform 35
- Android Build Tools 35.0.0

In Android Studio, open this project and use **Build > Build APK(s)**.

For a no-local-toolchain build, upload the project to GitHub and use the included Actions workflow. See `UPLOAD_AND_BUILD.md`.
