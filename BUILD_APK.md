# Build ChatArchive

Open the repository in Android Studio and allow Gradle to sync. The project uses Android Gradle Plugin 9.4.0, Gradle 9.6.0, Java 17 and Android API 36.

For local testing choose **Build > Build APK(s)**.

For Google Play choose **Build > Generate Signed App Bundle / APK > Android App Bundle**, create or select your upload keystore, and generate a signed `.aab`.

The permanent application ID is:

`com.elimara.chatarchive`

Do not change it after the first Play production release.
